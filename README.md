# Маркетплейс раритета с поддержкой аукционных торгов

Курсовая работа по дисциплине «Модели данных». КФ МГТУ им. Н.Э. Баумана, кафедра ИУК5. Никишин Д.В., ИУК5-51Б.
-
Чем эта система отличается от базовых Service Desk решений

В отличие от обычных систем учета заявок, где распределением задач занимается человек (диспетчер), а отчеты собираются вручную в электронных таблицах, данная система берет рутину на себя за счет алгоритмов маршрутизации и встроенной аналитики.

Инициатор просто описывает проблему свободным текстом. Система автоматически анализирует текст по словарю ключевых маркеров, вычисляет категорию и приоритет проблемы, а затем сама назначает заявку на профильного специалиста, у которого в данный момент наименьшая рабочая нагрузка. Дополнительно система ведет жесткий автоматический контроль сроков (SLA) на каждом этапе и в реальном времени строит аналитические графики для руководства.
